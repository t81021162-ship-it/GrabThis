SHELL COMMANDS
================================================================================

Once in the shell, try these commands:

  help       → Show all available commands
  moo        → Hear the cow speak 🐄
  whoami     → Show your identity
  status     → Display system status
  echo TEXT  → Print text
  clear      → Clear screen
  exit/quit  → Exit the shell

Example Session:
  moos> help
  moos> moo
  moos> status
  moos> echo "Hello from MOoOS!"
  moos> exit

MOO THE VIRUS ANTIVIRUS
================================================================================

Real-time threat detection with 5 threat levels:

  🟢 SAFE (0-24)         - No threats
  🟡 SUSPICIOUS (25-49)  - Investigate
  🟠 WARNING (50-74)     - Action recommended
  🔴 DANGEROUS (75-99)   - Stop & investigate
  💀 CRITICAL (100)      - Quarantine immediately

Detects:
  ✓ Dangerous code patterns (rm -rf /, SQL injection, etc.)
  ✓ Harmful filenames (malware, virus, backdoor, etc.)
  ✓ Compound threats (multiple patterns)
  ✓ Real-time scoring (0-100)

================================================================================
BUILDING FROM SOURCE
================================================================================

If you want to rebuild MOoOS from source:

1. Navigate to docs directory:
   $ cd /docs

2. View the README:
   $ cat README.md

3. Build everything:
   $ make build

4. Run components:
   $ make run              # Run in QEMU
   $ cargo run -p moos-shell
   $ cargo run -p moo-the-virus
   $ make test            # Run tests

Requirements:
  - Rust 1.70+
  - Cargo
  - QEMU (optional, for kernel testing)

================================================================================
TROUBLESHOOTING
================================================================================

Program won't start?
  → Try running from /bin/ directory
  → Check permissions: ls -l /bin/
  → View error messages carefully

Antivirus not finding threats?
  → It only scans what you give it
  → Use "1" to scan code input
  → Use "2" to check file names

Shell commands not working?
  → Type 'help' to see available commands
  → Commands are lowercase
  → Use 'echo TEXT' (not 'echo "TEXT"')
